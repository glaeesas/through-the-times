# Through the Times

Cinematic slideshow with Red Hot Chili Peppers – *Dani California*.

## Live site
Once GitHub Pages is enabled and the audio is uploaded:  
**https://glaeesas.github.io/through-the-times/**

## Setup (one-time)

1. **Upload the audio file**
   - Go to the repo → **Add file** → **Upload files**
   - Upload `dani-california.m4a` (must be named exactly that)
   - Commit the file

2. **Enable GitHub Pages**
   - Go to **Settings** → **Pages**
   - Source: **Deploy from a branch**
   - Branch: `main`  /  `/ (root)`
   - Save

3. Wait 1–2 minutes, then open the link above.

## How it works
- Click once → music starts + “Through the Times” title slide
- After a few seconds it fades into the photo slides
- Later you can replace the placeholder images with your own photos
